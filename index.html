    2. Dinamik dasturlash

    def change(n, coins):
    dp = [1] + [0] * n        # dp[0] = 1: bo'sh to'plam
    for c in coins:              # tangani tashqi siklda olamiz,
        for s in range(c, n + 1): # shunda tartib takrorlanmaydi
            dp[s] += dp[s - c]
    return dp[n]

    Murakkablik: vaqt O(n · k), xotira O(n), bu yerda k tanga turlari soni. Har bir tanga qo'shilishi G(x) ni bitta 1/(1−xᶜ) ko'paytuvchiga ko'paytirish bilan bir xil.
